# 🍔 Food API - Official Documentation

## Base URL
The production API is running behind a Cloudflare tunnel.
**Base URL:** `https://publication-missed-introduce-communist.trycloudflare.com/api/v1`
**Static Images Path:** `https://publication-missed-introduce-communist.trycloudflare.com/images/{filename}`

## Headers & Authentication
Most endpoints require a Bearer token generated by `/api/v1/auth/login`.
- **Authorization**: `Bearer <your_jwt_token>`
- **Content-Type**: `application/json`

---

## 🔐 1. Authentication (`/auth`)

### 1.1 Register User
- **Endpoint:** `POST /auth/register`
- **Requires Auth:** No
- **Body:**
```json
{
  "f_name": "Juan Perez",
  "phone": "12345678",
  "email": "juan@example.com",
  "password": "secretpassword"
}
```
- **Response (201 Created):**
```json
{
  "token": "eyJhbG...",
  "user": {
    "id": 23,
    "f_name": "Juan Perez",
    "phone": "12345678",
    "email": "juan@example.com"
  }
}
```

### 1.2 Login
- **Endpoint:** `POST /auth/login`
- **Requires Auth:** No
- **Body:**
```json
{
  "email": "juan@example.com",
  "password": "secretpassword"
}
```
- **Response (200 OK):** *(Same structure as Register)*

## 🍕 2. Products (`/products`)

### 2.1 Get Popular Products
- **Endpoint:** `GET /products/popular`
- **Requires Auth:** No
- **Description:** Returns foods tagged as popular (type_id = 2).
- **Response (200 OK):**
```json
{
  "total_size": 10,
  "products": [
    {
      "id": 1,
      "name": "Alitas BBQ",
      "description": "<p>Crispy chicken wings...</p>",
      "price": 8,
      "stars": 5,
      "people": 5,
      "selected_people": 5,
      "img": "https://publication-missed-introduce-communist.trycloudflare.com/images/alistas.jpg",
      "location": "Local",
      "type_id": 2,
      "type_name": "Popular food"
    }
  ]
}
```

### 2.2 Get Recommended Products
- **Endpoint:** `GET /products/recommended`
- **Requires Auth:** No
- **Description:** Returns foods tagged as recommended (is_recommend = 1).
- **Response:** *(Same structure as Popular Products)*

### 2.3 Get All Products
- **Endpoint:** `GET /products/all`
- **Requires Auth:** No
- **Query Parameters:** `?type_id=2` (optional filter)
- **Response:** *(Same structure as Popular Products)*

### 2.4 Get Product by ID
- **Endpoint:** `GET /products/:id`
- **Requires Auth:** No
- **Response (200 OK):** Returns a single product object.

## 🛒 4. Orders (`/order`)

### 4.1 Place Order
- **Endpoint:** `POST /order/place`
- **Requires Auth:** Yes
- **Body:**
```json
{
  "order_amount": 26, 
  "delivery_charge": 0,
  "order_note": "Please include extra napkins",
  "delivery_address": {
    "contact_person_name": "Juan",
    "contact_person_number": "123",
    "address": "Main St 123",
    "longitude": "-84.0",
    "latitude": "10.0"
  },
  "cart": [
    {
      "id": 1,
      "quantity": 2
    },
    {
      "id": 10,
      "quantity": 1
    }
  ]
}
```
*Note: The API calculates the final total based on the DB prices, so `order_amount` sent by the client is overridden by the real calculation to prevent fraud.*
- **Response (201 Created):**
```json
{
  "order_id": 100008,
  "total_amount": 26,
  "otp": "4812",
  "message": "Order placed successfully."
}
```

### 4.2 List Orders
- **Endpoint:** `GET /order/list`
- **Requires Auth:** Yes
- **Response (200 OK):**
```json
{
  "total_size": 1,
  "orders": [
    {
      "id": 100008,
      "user_id": 22,
      "order_amount": "26.00",
      "order_status": "pending",
      "order_note": "...",
      "delivery_address": "{\"address\":\"Main St 123\"}",
      "otp": "4812",
      "details": [
        {
          "id": 21,
          "order_id": 100008,
          "food_id": 1,
          "price": "8.00",
          "quantity": 2,
          "name": "Alitas BBQ",
          "img": "images/alistas.jpg"
        }
      ]
    }
  ]
}
```

### 4.3 Get Order Details
- **Endpoint:** `GET /order/:id`
- **Requires Auth:** Yes

### 4.4 Cancel Order
- **Endpoint:** `PUT /order/:id/cancel`
- **Requires Auth:** Yes
- **Description:** Can only be cancelled if `order_status` is still `'pending'`.
